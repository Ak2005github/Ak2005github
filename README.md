### About me

I'm a final-year Chemical Engineering student at IIT (BHU) Varanasi. I came to machine learning from an engineering background, and that shaped how I work: start from a real problem, model it carefully, and test whether the result actually holds up.

Over the last two years I've built projects across very different domains. I've counted dividing cells in cancer histopathology slides, ranked video games for 94K Amazon users, built an advisor agent that reasons over university documents, and picked fantasy cricket teams with an exact optimizer.

I enjoy building end-to-end ML/AI systems, from data processing and model development to deployment and production-ready applications.
